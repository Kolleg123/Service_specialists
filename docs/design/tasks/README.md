В дизайнерской ветке прототипы были встроены в существующее Flask-приложение (`static/app.js`, `static/style.css`, `static/index.html`), а не подготовлены как отдельные картинки. Визуальная система приведена к брендбуку: `#142D3A` (тёмно-синий), `#16A995` (бирюзовый), `#E0F5F0` (светлая мята), `#F6FAF9` (фон), `#6A8088` (серый), `#F4B86A` (акцент), DejaVu Sans.

В общей версии панель уведомлений использует серверные данные; макеты восстановления пароля и аудита доступны в галерее. Ниже описаны исходные прототипы и результаты их проверки.

## Границы исходных прототипов

Архив проекта содержит Flask/SQLite-приложение, но не содержит готовых backend-маршрутов и интеграций для новых возможностей. Поэтому новые сценарии выполнены как работающий демонстрационный интерфейс на стороне клиента:

- уведомления сформированы из тестовых данных; они не загружаются и не сохраняются на сервере;
- восстановление пароля не отправляет письмо и не меняет пароль в базе; для этого нужны серверная выдача/проверка одноразового токена, SMTP и безопасное сохранение нового хеша;
- журнал аудита показывает демонстрационные записи; серверная фиксация событий и API журнала не подключены.

Эти ограничения показаны пользователю в самих экранах, чтобы демонстрацию нельзя было принять за готовую серверную функцию. Скриншоты созданы в Chromium с замещёнными тестовыми API-ответами; они подтверждают внешний вид и клиентские взаимодействия, но не работу интеграций.

## Проверки

- `node --check static/app.js` — успешно.
- Браузерный прогон в Chromium: панель уведомлений для клиента, специалиста и администратора; отметка прочитанного; фильтрация/поиск журнала; все три шага восстановления пароля на 390 и 1280 px — успешно.
- Проверка ширины документа (`scrollWidth <= innerWidth`) на мобильном размере — успешно.
- `python -m compileall -q .` — успешно.
- `pytest -q` в текущем окружении не удалось запустить: в нём отсутствует Flask (`ModuleNotFoundError`), а установить зависимости не удалось из-за недоступности сети. Это ограничение окружения, а не подтверждённый провал тестов приложения.
