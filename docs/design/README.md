# Свободно. — макеты редизайна

Основа: `ai_version` / `a2ea466`. Макеты выполнены на существующем интерфейсе: сохранены фирменный зелёный, поиск, каталог, профиль, кабинеты и услуги. Это адаптивные HTML/CSS-макеты, реализованные в приложении; каждый экран ниже получен из браузера, а не из отдельного несвязанного рисунка.

Откройте **[интерактивную галерею](index.html)** локально в браузере. Выберите ширину 390 или 1280 px и состояние. PNG можно открыть отдельно по ссылкам ниже. Высота окна для снимков — 900 px; каталог снят целиком. Длинные окна имеют вертикальную прокрутку, без горизонтального переполнения; кнопка закрытия остаётся доступной.

## Решения

- **Первый экран:** фотография парикмахера за работой вместо интерьера. Заголовок и поиск остаются на светлом фоне; подпись на фотографии — на затемняющем градиенте. На мобильном поиск идёт перед изображением.
- **Помощник:** строка над фильтрами в обычном потоке страницы. Никаких плавающих элементов поверх каталога. Сам чат открывается только по действию пользователя и имеет кнопку закрытия.
- **Портреты:** один контейнер 4:3 и сохранение полного исходного кадра. Фон заполняет свободные поля, масштабирование при наведении отключено.
- **Профиль:** описание, образование, навыки и отзывы доступны на первом этапе; подробности раскрываются отдельно. На следующих этапах — компактное имя и портрет, без повторения длинного профиля.
- **Расписание:** четыре даты на странице, явная навигация в обе стороны и переход через поле даты. Последняя опубликованная дата указана текстом. Нет обещания несуществующих слотов после конца расписания.
- **Подтверждение:** специалист, услуга, дата и время, часовой пояс, длительность, формат, стоимость за участника и итог. Адрес только для выездных услуг.
- **Смена услуги:** дата и время очищаются немедленно; причина объявляется через `role=status`. Устаревшие ответы не возвращают прежний выбор.
- **Конфликт:** серверный 409 возвращает ко второму этапу с актуальными альтернативами. Нельзя повторно отправить прежний слот без нового выбора.
- **Загрузка:** видимый индикатор с `aria-busy`, таймаут 15 секунд; нет пустого неотзывчивого окна.
- **Пустое состояние:** объяснение, повторное обновление, выбор другой услуги или специалиста.
- **Ошибка:** понятный текст, отдельная кнопка повтора; после успешной загрузки снова отображаются даты.

## Управление

Клавиши Tab/Shift+Tab перемещают фокус; Enter/Space активируют кнопки. Даты и время — обычные кнопки с `aria-pressed`; этап отмечен `aria-current=step`. При выборе времени фокус переходит к «Продолжить», при переходе к подтверждению — к заголовку. Escape закрывает диалог. Нельзя перейти к подтверждению без выбранного доступного слота. Поле услуги остаётся доступным на всех этапах, кроме отправки запроса.

## Как сняты состояния

Снимки «до» сделаны до редактирования файлов на базовом коммите. Для «после» используется `tests/browser/design.spec.js` с отдельной временной базой. Загрузка удерживает ответ API; пустое состояние получает `slots: []`; ошибка получает HTTP 503; кнопка повторной загрузки затем обращается к настоящему серверу. Это воспроизводимые макеты состояний, а не утверждение о сбое работающего сервера. Остальные снимки используют реальные демонстрационные данные.

Даты в изображениях относятся к моменту съёмки (13 ноября 2026 года); тесты вычисляют новые даты при запуске. Пользовательская база не изменяется и не пересоздаётся для получения скриншотов.
