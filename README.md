# Свободно.

Учебный веб-сервис поиска специалистов и записи на услуги в Кирове. Клиенты выбирают услугу и время, специалисты управляют своими услугами и расписанием, администратор рассматривает заявки и модерирует каталог.

[Таблица управления проектом команды](https://docs.google.com/spreadsheets/d/1F8kLkNJwpL_PPwDWPexMuL3MSwgfiM43kKV2SpV3pzY/edit)

## Технологии и запуск

Python 3.12+, Flask 3.1.2, SQLite и Werkzeug 3.1.3. Интерфейс на HTML, CSS и JavaScript без сборки. Для восстановления пароля используется SMTP.

Скачайте репозиторий и откройте терминал в папке с `app.py`. Используйте Python 3.12 или новее.

**Windows (CMD)**

```cmd
py -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
python app.py
```

**Linux и macOS**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

Откройте [http://127.0.0.1:5000](http://127.0.0.1:5000). Порт задаётся переменной `PORT`. При следующих запусках достаточно активировать окружение и выполнить `python app.py`.

### Режимы и первый администратор

- По умолчанию действует обычный режим (`DEMO_MODE=false`, база `instance/svobodno.sqlite`). Каталог новой установки пуст, регистрация открыта, общих аккаунтов нет. Создайте администратора командой `python -m flask --app app:create_app create-admin` и введите почту и пароль по приглашению.
- Для демонстрации установите `DEMO_MODE=true` в `.env` и перезапустите приложение. Демо-каталог и быстрый вход используют `instance/svobodno-demo.sqlite`. При первом запуске создаются примеры специалистов, услуг и слотов. Актуальное расписание мастер ведёт в кабинете. Все даты относятся к Кирову (UTC+3).
- `DATABASE_PATH` и `DEMO_DATABASE_PATH` позволяют задать другие файлы. Схема обновляется автоматически. Для действующей установки сначала выполните [переход с резервной копией](docs/runtime-and-yookassa.md#переход-существующей-установки).

Для локального HTTP оставьте `COOKIE_SECURE=false`. Для сервера задайте HTTPS в `APP_BASE_URL` и `COOKIE_SECURE=true`. `APP_SECRET` можно оставить пустым при локальном запуске: приложение создаст ключ в `instance/session.key`. На сервере задайте случайный `APP_SECRET` длиной от 32 символов через защищённое окружение. Храните `.env` вне Git.

## Восстановление пароля по email

1. Если `.env` ещё нет, скопируйте `.env.example` в `.env` рядом с `app.py`. Укажите адрес сайта в `APP_BASE_URL` и задайте собственный случайный `APP_SECRET`. При работе по HTTPS установите `COOKIE_SECURE=true`.
2. Задайте настройки своего почтового провайдера через `SMTP_HOST`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM_EMAIL` и `SMTP_FROM_NAME`. Для Gmail используется `smtp.gmail.com`, порт `587`, адрес отправителя и пароль приложения Google с включённой двухэтапной проверкой. Храните реальные данные только в локальной или серверной конфигурации.
3. Перезапустите приложение, в форме входа нажмите «Забыли пароль?» и введите адрес зарегистрированного аккаунта. Одноразовая ссылка действует 30 минут. После успешного сброса все старые сеансы завершаются. При проблеме доставки проверьте папку «Спам» и журнал сервера.

Отправку ссылки и сброс пароля вручную проверили на рабочем сервере.

[Подробности настройки SMTP и сценарии восстановления](docs/password-recovery.md)

## Роли и возможности

| Роль | Возможности |
|---|---|
| Клиент (`client`) | Запись и отмена до начала встречи, история записей и поиска, отзывы после завершения встречи, заявка на статус специалиста |
| Специалист (`master`) | Запись к другим специалистам, свои записи, отзывы и история поиска, свои услуги и расписание, записи своих клиентов, отмена и завершение встреч. Запись на собственную услугу запрещена |
| Администратор (`admin`) | Рассмотрение заявок специалистов, модерация услуг и отзывов, управление видимостью каталога, просмотр и отмена записей, поддержка, справочник категорий и журнал действий |

Каталог поддерживает поиск, категории, фильтры по цене и формату, карточки специалистов и помощника с рекомендациями по ключевым словам. Доступны индивидуальные и групповые слоты, недельное расписание с перерывами и запись на день без выбора времени. Новые услуги проходят отдельную модерацию. Уведомления о записях и решениях по заявкам доступны в кабинете.

### Как стать специалистом

1. Зарегистрируйтесь или войдите как клиент. В личном кабинете нажмите «Стать специалистом», заполните анкету и отправьте её.
2. Пока заявка рассматривается, доступна вкладка «Статус заявки». При отклонении в кабинете появится причина и форма для повторной подачи с предыдущими данными.
3. После одобрения приложение создаст профиль специалиста для того же аккаунта. Результат появится в панели «Уведомления». Откройте или обновите кабинет, чтобы увидеть переключатель «Режим кабинета». В режиме «Клиент» доступны свои записи, отзывы и статус заявки, в режиме «Специалист» — услуги, расписание и записи клиентов.

Администратор открывает «Заявки специалистов», проверяет анкету и выбирает «Одобрить» или «Отклонить». Для отклонения требуется причина. Статусы заявки — `pending`, `approved`, `rejected`. Для услуг есть отдельная вкладка «Заявки на услуги».

## Поддержка

- Клиент и специалист могут создать обращение в разделе «Поддержка», открыть ответ и отозвать обращение на рассмотрении. Ссылка «Не нашли нужную категорию?» доступна в форме создания и изменения услуги. Она открывает обращение и сохраняет введённые данные услуги.
- Во вкладке «Обращения» администратор видит отправителя, статус и дату, может фильтровать и сортировать список. Чтобы завершить обработку, нужно отправить непустой ответ. Обработанные и отозванные обращения остаются в истории.
- Новые обращения и ответы появляются в панели «Уведомления». Нажатие на уведомление открывает детали обращения. Списки, статусы и счётчики обновляются в открытом кабинете примерно раз в 10 секунд.

## Категории услуг

Начальный справочник содержит 15 направлений и 137 категорий.

- В кабинете «Мои услуги» выберите направление и конкретную категорию. Поиск по названию категории работает по всему справочнику или внутри выбранного направления. Для добавления и редактирования услуги категория обязательна. Профессия и направление в анкете специалиста остаются данными профиля.
- В публичном каталоге видны только направления и категории, в которых у активных специалистов есть опубликованные услуги. Фильтры по направлению, категории, формату и цене работают вместе. Если открыть карточку из результатов, по умолчанию будет выбрана подходящая услуга, а в списке останутся все опубликованные услуги специалиста.
- Новая категория услуги отображается в каталоге после одобрения. Пока администратор рассматривает изменения, остаётся доступна опубликованная версия. Скрытие или удаление последней услуги убирает категорию при обновлении каталога, записи клиентов сохраняются.
- В разделе «Категории услуг» администратор видит весь справочник и количество связанных и опубликованных услуг. Группы и категории можно добавлять, переименовывать и искать по названию. Категорию можно перенести в другую группу с сохранением связей.
- Удаление требует подтверждения. Для категории со связанными услугами или черновиками администратор выбирает замену. Для непустой группы он выбирает группу назначения. Перенос и удаление выполняются одной транзакцией. Приложение архивирует записи справочника при наличии исторических связей и сохраняет записи клиентов и отзывы.
- Справочник заполняется один раз. Переименования и удаления администратора сохраняются после перезапуска. При обновлении существующей SQLite-базы приложение добавляет таблицу обращений и новые поля справочника, профилей и уведомлений. Однозначным старым услугам категория назначается автоматически.
- Список категорий в форме специалиста и фильтры публичного каталога обновляются в фоне. Если выбранную категорию удалили, форма сохраняет остальные поля и просит выбрать другую.
- Для ручной проверки добавьте услугу в пока пустой категории, одобрите её через «Заявки на услуги» и найдите мастера в каталоге. Затем измените категорию, повторно одобрите услугу и проверьте фильтр ещё раз.

## Тестовая оплата

Интеграция с ЮKassa работает через тестовый магазин. Реальные списания не выполняются. Оплата выключена по умолчанию. При включении клиент может оплатить предстоящую запись в тестовом режиме. Предоплата добровольная. Сервер берёт сумму из записи и сверяет статус с API ЮKassa. Кабинет обновляет статус оплаты. Успешную тестовую оплату вручную проверили на рабочем сервере.

Настройки `PAYMENTS_ENABLED`, `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`, `YOOKASSA_RETURN_URL` и `YOOKASSA_WEBHOOK_TOKEN` перечислены в `.env.example`. [Подключение, возвраты и обслуживание](docs/runtime-and-yookassa.md#тестовая-оплата-через-юkassa).

## Демо-вход

Вход выполняется по логину или почте и паролю. При регистрации указывается неизменяемый логин. Почту можно изменить в профиле. При `DEMO_MODE=true` в форме входа доступны кнопки быстрого входа для клиента, мастера, преподавателя с групповыми услугами и администратора. Демо-аккаунты общие, поэтому для показа используйте вымышленные данные. Для проверки восстановления укажите почту, к которой у вас есть доступ.

## Как проверить заявки

1. Отправьте заявку с нового аккаунта. Проверьте статус «На проверке» и отсутствие второй формы.
2. В отдельном профиле браузера или в режиме инкогнито войдите администратором и отклоните заявку с причиной. Откройте кабинет клиента, проверьте причину и уведомление, подайте заявку повторно.
3. Одобрите новую заявку. В кабинете того же пользователя переключите оба режима, откройте «Мои услуги» и «Моё расписание». Запишитесь к другому специалисту. Запись появится в «Моих записях» режима «Клиент».
4. Добавьте услугу и слот, одобрите услугу через «Заявки на услуги» и откройте свой профиль в каталоге. В своём профиле появится сообщение о запрете записи.

Точечная проверка API на временной SQLite-базе:

```bash
python -m pytest -q tests/test_specialist_registration.py
```

## Управление услугами, записями и уведомлениями

- Нажатие на текст уведомления открывает подробности и отмечает его прочитанным. Список обновляется примерно раз в 10 секунд, пока кабинет открыт.
- Администратор может фильтровать заявки специалистов по статусу и раскрывать нужную анкету.
- В «Моих услугах» мастер может изменить или удалить услугу. Изменения опубликованной услуги проходят модерацию, а прежняя версия доступна до одобрения. При изменении длительности или формата после одобрения для ручного расписания нужно добавить новые слоты. Удаление сохраняет историю и предстоящие записи.
- Мастер может указать причину отмены одной или всех своих предстоящих записей. Причина видна клиенту в уведомлении и истории.

В «Заявках на услуги» доступны фильтры по текущему статусу. В кабинете администратора счётчики показывают количество заявок на проверке. Открытый раздел кабинета и каталог обновляются примерно раз в 10 секунд. В поддержке, справочнике и формах услуг фоновые обновления сохраняют введённый текст и выбранные фильтры.

Внешние уведомления обрабатываются отдельно. По умолчанию используется тестовый адаптер. Доставку через вебхук нужно настроить явно. SMTP используется для восстановления пароля.

## Резервное копирование

Администратор может создать копию текущей SQLite-базы и проверить её восстановлением в отдельный файл. Приложение проверяет целостность копии. Для восстановления экземпляра сохраните также папку загрузок и конфигурацию. Порядок действий описан в [инструкции по обновлению и откату](docs/runtime-and-yookassa.md#переход-существующей-установки).

## Известные ограничения

- Группы с несколькими местами работают через ручные слоты. Чтобы перенести встречу, отмените её до начала и создайте новую запись.
- Видеосвязь отсутствует. Для нового профиля используется стандартная заглушка фото.
